## EP0 T0.2.a — Типизированный config-слой

### Цель

Реализовать типизированный слой конфигурации, который инкапсулирует `env` и предоставляет удобный API для остальных модулей.

### Требования

- Определить TypeScript‑интерфейсы:
  - `DatabaseConfig`, `FarmDatabaseConfig`, `MqttConfig`, `SlackConfig`, `UnlinkDeadConfig`, `ProviderConfig` и общий `AppConfig`.
- Реализовать модуль `src/config/env.ts`:
  - чтение всех необходимых `process.env.*`;
  - валидация (обязательные поля, допустимые значения);
  - преобразование типов (number/bool/array);
  - значения по умолчанию (как описано в архитектуре).
- Реализовать модуль `src/config/index.ts`:
  - формирование `const config: AppConfig = { ... }`;
  - экспорт по умолчанию;
  - запрещено использовать `process.env` вне этого модуля (линтер‑правило/договорённость).

### Acceptance criteria

- Все инфраструктурные и доменные модули используют `config` вместо прямого обращения к `process.env`.
- При отсутствии критичных переменных конфиг кидает понятное исключение на старте (fail-fast).
