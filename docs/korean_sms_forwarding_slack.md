# Корейские номера и форвардинг SMS в Slack

Документ описывает, как диагностировать кейсы вида «в бот не приходят SMS» для корейских устройств с мобильным софтом форвардинга.

## Что важно знать

- Номера из Кореи часто приходят в локальном формате, например `01081055611`.
- В БД и логике поиска обычно используется международный вид: `82` + номер без ведущего `0`.
- Пример преобразования:
  - `01081055611` -> `821081055611`
  - для `sms_devices.phones` обычно ищем с `+`: `+821081055611`

## Где смотреть данные

- `public.sms_devices` — состояние устройства и heartbeat.
  - Ключевое поле: `updated_at` (ожидается обновление примерно раз в минуту).
  - Если `updated_at` старше нескольких минут, устройство вероятно не в сети.
- `public.with_tech_farm_logs` — входящие SMS, которые прошли через форвардинг.
  - Ключевое поле: `created_at` (время получения SMS).
- `public.with_tech_farm` — используется для определения, в чей Slack DM отправлять OTP.

## Базовая диагностика по номеру

Для входного номера `01081055611`:

```sql
-- 1) Проверяем последние SMS по международному номеру
select *
from public.with_tech_farm_logs
where phone = 821081055611
order by created_at desc
limit 5;

-- 2) Проверяем, живо ли устройство с этим номером
select *
from public.sms_devices
where '+821081055611' = any(phones);
```

Интерпретация:

- Если в `with_tech_farm_logs` давно нет новых записей и
- в `sms_devices.updated_at` старый timestamp,
- то причина обычно не в боте/Slack, а в том, что телефон офлайн (нет связи/интернета/питания/приложение не работает в фоне).

## Пример из инцидента

- Номер из запроса: `01081055611` -> `821081055611`.
- Последняя SMS в `with_tech_farm_logs`: `2026-04-19 01:48:11.497099`.
- `sms_devices.updated_at`: `2026-04-19 16:55:16.289925+00`.
- Вывод: телефон не на связи, поэтому новые SMS не форвардятся.

## Что отвечать в поддержку

Если устройство офлайн, используем стандартный ответ в стиле процесса с индийскими телефонами:

- Проверить телефон физически (питание, сеть, интернет, приложение форвардинга, разрешения).
- Убедиться, что устройство снова начинает присылать heartbeat (обновляется `sms_devices.updated_at`).
- После восстановления проверить, что появляются новые записи в `with_tech_farm_logs`.

Рекомендуемый шаблон:

> Проверили устройство по номеру `<номер>`: heartbeat не обновляется несколько минут, телефон не в сети.  
> Нужно проверить устройство (связь/интернет/приложение).  
> После возврата в сеть SMS снова начнут попадать в Slack.

## Связь со Slack DM

- Таблица `with_tech_farm` определяет, кому отправлять OTP в Slack DM.
- Если SMS есть в `with_tech_farm_logs`, но DM не пришел, дополнительно проверяем:
  - корректный маппинг в `with_tech_farm`,
  - актуальность Slack-идентификаторов и интеграции.
