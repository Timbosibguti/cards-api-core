# Architecture Decision Records (ADR)

Каждый ADR описывает одно принятое решение: контекст, варианты, выбранный вариант и последствия.

## Формат файла

Имя: `NNNN-краткое-название.md` (например, `0001-framework-choice.md`).

Содержание:

```markdown
# ADR-NNNN: Краткое название

## Статус
Принято | Отложено | Устарело

## Контекст
Почему нужно принять решение.

## Варианты
- Вариант A: ...
- Вариант B: ...

## Решение
Выбранный вариант и краткое обоснование.

## Последствия
Плюсы, минусы, что нужно учесть при реализации.
```
